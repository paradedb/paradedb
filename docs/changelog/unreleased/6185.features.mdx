`pdb.agg()` now runs over joins and on single tables whose group count is past the bucket limit, with `terms` (`size`, `min_doc_count`, `missing`, `order`), `sum`, `avg`, `min`, `max`, `value_count`, `cardinality`, and nested `aggs`.

  Buckets with equal counts now come back in key order in every query, so a `size` cut among equal counts keeps the smallest keys, and a NULL bucket over a numeric field reads as `null` instead of an extreme number. A spec with nested `aggs` now also works beside a `GROUP BY` on a single table.
