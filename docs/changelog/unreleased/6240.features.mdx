A `GROUP BY` on a string column of a search index now groups on the index's term ordinals first and decodes one value per group, instead of decoding every input row. A deferred string column is also carried as one 64-bit integer per row rather than a union array, which makes it cheaper to hash, compare and move through joins, and lets it pass through the null-extended side of an outer join.
