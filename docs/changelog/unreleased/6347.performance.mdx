Added segment pruning from persisted per-segment statistics. Execution rebuilds conservative proofs against its current segment set, skips segments that a query or an execution-time dynamic filter cannot match, and omits a range-partition filter wherever a segment's bounds prove it redundant. Missing or unreadable statistics retain the segment. `EXPLAIN (ANALYZE)` reports `range_filters_removed` and `segments_pruned_dynamic_range`.
