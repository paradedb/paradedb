Autocomplete suggests products as the user types. For example, typing `wir` can match a description containing `wireless`.

## Create an N-gram Index

The following example rebuilds `search_idx` with an N-gram field named `description_ngram` that matches fragments of three to eight characters, then queries it for `wir`. Run the index setup once, or add it to a migration. Each search request only needs the query.

<Tabs>
<Tab title="SQL">

```sql
DROP INDEX IF EXISTS search_idx;
CREATE INDEX search_idx ON mock_items
USING paradedb (
  id, description, embedding vector_cosine_ops, category, rating,
  in_stock, created_at, last_updated_date, latest_available_time, metadata, weight_range,
  (description::pdb.ngram(3,8,'alias=description_ngram'))
)
WITH (key_field='id');

SELECT id, description, rating, category FROM mock_items
WHERE description::pdb.alias('description_ngram') &&& 'wir'
ORDER BY pdb.score(id) DESC, id
LIMIT 5;
```

  .select({
    id: mockItems.id,
    description: mockItems.description,
    rating: mockItems.rating,

  })
  .from(mockItems)
  .where(
    search.matchAll(

      "wir",

  )
  .orderBy(desc(search.score(mockItems.id)), mockItems.id)

## Add a Suggestions Endpoint

Create a `GET /api/suggestions?q=wir` endpoint that runs the query above with the user's input in place of `wir`. Trim the input and pass it as a query parameter or ORM value. Keep the result limit at five.

Return the rows in a `suggestions` array, with each product's `id`, `description`, `rating`, and `category`. For input shorter than three characters, return `{"suggestions": []}` without querying.

The `&&&` operator requires every N-gram in the input to match. It matches fragments anywhere in a word. See [Match Conjunction](/reference/full-text/match#match-conjunction) and [N-gram](/reference/tokenizers/available-tokenizers/ngrams) for details.

## Connect the Search Box

The following example calls the endpoint 200 milliseconds after the user stops typing. It cancels the previous request and ignores older responses to keep the suggestions in sync with the input.

```html
<label for="product-search">Find a product</label>
<input id="product-search" type="search" autocomplete="off" />
<p id="search-status" role="status"></p>
<ul id="suggestions"></ul>

<script type="module">
  const input = document.querySelector("#product-search");
  const status = document.querySelector("#search-status");
  const list = document.querySelector("#suggestions");
  let timer;
  let controller;
  let revision = 0;

  input.addEventListener("input", () => {
    const current = ++revision;
    clearTimeout(timer);
    controller?.abort();
    list.replaceChildren();
    const query = input.value.trim();
    status.textContent = "";
    if (query.length < 3) return;

    status.textContent = "Searching…";
    timer = setTimeout(async () => {
      controller = new AbortController();
      try {
        const response = await fetch(
          "/api/suggestions?" + new URLSearchParams({ q: query }),
          { signal: controller.signal },
        );
        if (!response.ok) throw new Error("Search failed");
        const { suggestions } = await response.json();
        if (current !== revision) return;
        for (const product of suggestions) {
          const item = document.createElement("li");
          const link = document.createElement("a");
          // Replace this route with your application's product page.
          link.href = "/products/" + encodeURIComponent(product.id);
          link.textContent = product.description;
          item.append(link);
          list.append(item);
        }
        status.textContent = suggestions.length
          ? suggestions.length + " suggestions"
          : "No matching products";
      } catch (error) {
        if (current === revision && error.name !== "AbortError") {
          status.textContent = "Search unavailable. Try typing again.";
        }
      }
    }, 200);
  });
</script>
```

The suggestions are links that users can reach with Tab and open with Enter. Arrow-key navigation would require a combobox implementation. Replace `/products/` with your application's product route.

The example uses `textContent` to display product descriptions as text. Clearing the input also clears the suggestions. Empty results and failed requests display separate messages below the search box.
