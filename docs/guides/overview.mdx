Guides show how to combine ParadeDB features into common application patterns, including a filter sidebar, a search box, and a question-answering flow. Each walkthrough connects database queries to application behavior. Choose a use case and select your SQL or ORM tab.

These guides build on the table, index, and connection from [Getting Started](/start/install). For individual query features, see the Reference pages for [vector search](/reference/vector/querying), [hybrid search](/reference/hybrid/rrf), and [More Like This](/reference/full-text/more-like-this).
