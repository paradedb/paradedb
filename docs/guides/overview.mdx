Guides show how to combine ParadeDB features into common application patterns, from product search and autocomplete to recommendations and retrieval for language models. Choose a use case, select your SQL or ORM tab, and adapt the queries to your application.

These guides build on the table, index, and connection from [Getting Started](/start/install). For detailed syntax and configuration options, see the [Reference](/reference/overview).
