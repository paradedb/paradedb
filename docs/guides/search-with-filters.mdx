Faceted search returns matching products along with counts for each category or rating. These counts let users narrow their search with filters.

## Search Parameters

Store the search text and filters in the URL so users can share a search or return to it with the Back button. For example, `?q=shoes&category=Footwear&min_rating=4` searches for shoes in Footwear with a rating of at least four.

Validate the rating as an integer from 1 to 5. Pass the search text and filters as query parameters or ORM values, and omit filters that the user has not selected.

## Query Results and Counts

The following query returns the five highest-rated products that match these filters. The category and rating counts cover all matching products, before the result limit.

<Tabs>
<Tab title="SQL">

```sql
SELECT id, description, rating,
       pdb.agg('{"terms": {"field": "category"}}') OVER () AS categories,
       pdb.agg('{"terms": {"field": "rating"}}') OVER () AS ratings
FROM mock_items
WHERE description ||| 'shoes'
  AND category = 'Footwear'
  AND rating >= 4
ORDER BY rating DESC, id
LIMIT 5;
```

</Tab>

<Tab title="Drizzle">

Use `await import(...)` for additional imports and paste the query into the REPL’s `.editor` mode. See [Connect Your App](/start/connect-your-app#drizzle).

```ts
import { and, desc, eq, gte } from "drizzle-orm";
import { search } from "@paradedb/drizzle-paradedb";

const rows = await db
  .select({
    id: mockItems.id,
    description: mockItems.description,
    rating: mockItems.rating,
    categories: search.agg({ terms: { field: "category" } }).over(),
    ratings: search.agg({ terms: { field: "rating" } }).over(),
  })
  .from(mockItems)
  .where(
    and(
      search.matchAny(mockItems.description, "shoes"),
      eq(mockItems.category, "Footwear"),
      gte(mockItems.rating, 4),
    ),
  )
  .orderBy(desc(mockItems.rating), mockItems.id)
  .limit(5);

console.log(rows);
console.log(rows[0]?.categories, rows[0]?.ratings);
```

<Tab title="SQLAlchemy">

```python
from sqlalchemy import select
from sqlalchemy.orm import Session
from paradedb.sqlalchemy import facets, pdb, search

base = (
    select(MockItem.id, MockItem.description, MockItem.rating)
    .where(search.match_any(MockItem.description, "shoes"), MockItem.category == "Footwear", MockItem.rating >= 4)
    .order_by(MockItem.rating.desc(), MockItem.id)
    .limit(5)
)
stmt = base.add_columns(
    pdb.agg(facets.terms(field="category")).over().label("categories"),
    pdb.agg(facets.terms(field="rating")).over().label("ratings"),
)
with Session(engine) as session:
    rows = session.execute(stmt).all()
    print(rows)
    if rows:
        print(rows[0].categories, rows[0].ratings)
```

## Display Results and Counts

Return the products and facet counts in the same response. Each terms aggregation has a `buckets` array with a `key` for the field value and a `doc_count` for the number of matches. Window aggregations repeat these counts on every row, so read them from the first row.

Use the category buckets for the sidebar choices. Rating buckets count each rating separately. For example, the bucket for four counts four-star products, not all products rated four or higher.

The five-product limit does not apply to the counts. If the query returns no rows, display an empty result list and empty facets.

## Apply Filters

When a user selects a filter, update the URL and rerun the query. Replace the products and counts together.

Counts include the selected filters. Selecting Footwear, for example, removes other categories from the buckets. Keep the selected filters visible even when there are no results, so the user can clear them.

To show other category choices after a category is selected, run a separate category aggregation without that filter. Keep the search text and remaining filters in this query.

See [Facets](/reference/aggregates/facets) and [Terms](/reference/aggregates/bucket/terms) for more on aggregations and bucket options.
