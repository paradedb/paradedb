Find products whose embeddings are close to a query, then restrict the results to a category.

## Find the nearest products

The Start index already includes `embedding vector_cosine_ops`. Use cosine distance with the eight-dimensional demo vector for “running shoes.” In your application, generate query and document embeddings with the same model.

<Tabs>
<Tab title="SQL">

```sql
SELECT id, description
FROM mock_items
WHERE id @@@ pdb.all()
ORDER BY embedding <=> '[-0.02, 0.47, -0.76, 0.13, 0.34, 0.04, 0.19, -0.19]'
LIMIT 5;
```

Keep the match-all search predicate and `LIMIT`: ParadeDB uses them to perform Top K vector retrieval.

Replace the match-all predicate with a category filter to retrieve only footwear. The default tokenizer lowercases category terms, so query `footwear`.

```sql
SELECT id, description
FROM mock_items
WHERE category === 'footwear'
ORDER BY embedding <=> '[-0.02, 0.47, -0.76, 0.13, 0.34, 0.04, 0.19, -0.19]'
LIMIT 5;
```

Load any additional imports with `await import(...)`, then paste the query body in the REPL’s `.editor` mode as described in [Connect Your App](/start/connect-your-app#drizzle).

```ts
import { search } from "@paradedb/drizzle-paradedb";

const queryEmbedding = [-0.02, 0.47, -0.76, 0.13, 0.34, 0.04, 0.19, -0.19];

await db
  .select({ id: mockItems.id, description: mockItems.description })
  .from(mockItems)
  .where(search.all(mockItems.id))
  .orderBy(search.cosineDistance(mockItems.embedding, queryEmbedding))
  .limit(5);
```

from paradedb.vector import CosineDistance

query_embedding = [-0.02, 0.47, -0.76, 0.13, 0.34, 0.04, 0.19, -0.19]
