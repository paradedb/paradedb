ParadeDB Cloud is our fully managed platform for running ParadeDB, currently
available in private preview. It manages the full Postgres lifecycle, including
backups, replication, and autoscaling, with first-class support for ParadeDB
indexes. Every deployment runs [ParadeDB Enterprise](/operate/deploy/enterprise).

## How It Works

ParadeDB Cloud uses [CloudNativePG](https://github.com/cloudnative-pg/cloudnative-pg),
a production-proven foundation for highly available Postgres on Kubernetes and a
[CNCF project](https://www.cncf.io/projects/cloudnativepg/) within the Linux
Foundation ecosystem. We manage the infrastructure so you can focus on your
data and queries.
