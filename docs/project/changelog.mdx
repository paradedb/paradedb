The changelog records user-facing ParadeDB releases, including new features,
performance improvements, stability fixes, and compatibility notes.

Release notes are organized by version in the sidebar. Each version page includes
the docs summary for that release and links to the corresponding GitHub release
when the full GitHub changelog is available.
