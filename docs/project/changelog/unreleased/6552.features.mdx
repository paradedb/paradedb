A multi-field `partition_by` now cuts its first field into global ranges and each later field inside them, so a range co-partitioned join on the first field takes whole segments. A `field=N` count, as in `partition_by = 'id=8, owner_user_id'`, sets how many ranges a field is cut into. A range co-partitioned join now cuts on the side whose segment edges land inside the fewest rows of the other side, instead of the larger side's edges.
