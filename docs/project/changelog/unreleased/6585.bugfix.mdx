Fixed scores in range co-partitioned joins (`paradedb.enable_range_partitioned_join`). A row in a segment that crosses a partition's edges scored `1.0` too high, so a Top K by score could return the wrong rows, and a `LEFT JOIN` Top K could lose rows with a NULL join key. Those segments also keep block-WAND pruning for a Top K by score.
