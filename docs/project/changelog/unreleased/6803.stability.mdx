Fixed Join Scan declining queries whose `SELECT` list contains an expression over a column that is not a fast field, such as `'x/' || s.path` (#6576). Postgres now computes these expressions from the rows Join Scan returns, after the `LIMIT`. An expression used in `ORDER BY` or `DISTINCT` must still use fast fields, and an expression containing a volatile function still declines Join Scan.
