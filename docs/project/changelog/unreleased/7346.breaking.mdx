Renamed the IVF index option `max_leaf_size` to `target_leaf_size`. The value is the target number of indexed vectors per clustering leaf. Training scales it by `training_sample_ratio`; it does not cap the number of indexed vectors assigned to a cluster. Indexes that explicitly store `max_leaf_size` must be updated with `ALTER INDEX ... SET (target_leaf_size = ...)` or recreated.
