---
title: Filters
description: Compute aggregations over multiple filters in one query
canonical: https://www.paradedb.com/docs/reference/aggregates/bucket/filters
---

The filters aggregation allows a single query to return aggregations for multiple search queries at a time.
To use this aggregation, pass `pdb.agg` to the left-hand side of `FILTER` and a search query to the right-hand side.
For example:

<CodeGroup>
```sql SQL
SELECT
    pdb.agg('{"filter": "*"}')
    FILTER (WHERE category === 'electronics') AS electronics_count,
    pdb.agg('{"filter": "*"}')
    FILTER (WHERE category === 'footwear') AS footwear_count
FROM mock_items;
```

```ts Drizzle
import { search } from "@paradedb/drizzle-paradedb";

await db
  .select({
    electronicsCount: search
      .agg({ filter: "*" })
      .filter(search.term(mockItems.category, "electronics")),
    footwearCount: search
      .agg({ filter: "*" })
      .filter(search.term(mockItems.category, "footwear")),
  })
  .from(mockItems);
```

```python Django
from django.db.models import Q
from paradedb import Agg, ParadeDB, Term

MockItem.objects.aggregate(
    electronics_count=Agg(
        '{"filter": "*"}',
        filter=Q(category=ParadeDB(Term('electronics'))),
    ),
    footwear_count=Agg(
        '{"filter": "*"}',
        filter=Q(category=ParadeDB(Term('footwear'))),
    ),
)
```

```python SQLAlchemy
from sqlalchemy import select
from sqlalchemy.orm import Session
from paradedb.sqlalchemy import pdb, search

stmt = select(
    pdb.agg({"filter": "*"})
    .filter(search.term(MockItem.category, "electronics"))
    .label("electronics_count"),
    pdb.agg({"filter": "*"})
    .filter(search.term(MockItem.category, "footwear"))
    .label("footwear_count"),
).select_from(MockItem)

with Session(engine) as session:
    session.execute(stmt).all()
```

```ruby Rails
result = MockItem.facets_agg(
  electronics_count: ParadeDB::Aggregations.filtered(
    { filter: "*" },
    field: :category,
    term: "electronics"
  ),
  footwear_count: ParadeDB::Aggregations.filtered(
    { filter: "*" },
    field: :category,
    term: "footwear"
  )
)
```

```cs EF Core
await dbContext
    .MockItems.Select(item => new
    {
        ElectronicsCount = EF.Functions.AggFilter(
            new { filter = "*" },
            EF.Functions.Term(item.Category, "electronics")
        ),
        FootwearCount = EF.Functions.AggFilter(
            new { filter = "*" },
            EF.Functions.Term(item.Category, "footwear")
        )
    })
    .ToListAsync();
```

</CodeGroup>

<Note>
  `===` matches indexed terms exactly, so the casing depends on `category`'s
  tokenizer. With the default tokenizer or
  [`literal_normalized`](/reference/tokenizers/available-tokenizers/literal-normalized),
  terms are lowercased: use `electronics`. With the
  [`literal`](/reference/tokenizers/available-tokenizers/literal) tokenizer,
  which preserves the original casing, use `Electronics`.
</Note>
