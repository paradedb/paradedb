---
title: How Token Filters Work
description: Token filters apply additional processing to tokens like lowercasing or stemming
canonical: https://www.paradedb.com/docs/reference/token-filters/overview
---

After a [tokenizer](/reference/tokenizers/overview) splits up text into tokens, token filters
apply additional processing to each token. Common examples include [stemming](/reference/token-filters/stemming)
to reduce words to their root form, or [ASCII folding](/reference/token-filters/ascii-folding) to remove accents.

Token filters can be added to any tokenizer besides the [literal](/reference/tokenizers/available-tokenizers/literal) tokenizer, which by definition
must preserve the source text exactly.

To add a token filter to a tokenizer, append a configuration string to the argument list:

```sql
CREATE INDEX search_idx ON mock_items
USING paradedb (id, (description::pdb.simple('stemmer=english', 'ascii_folding=true')))
WITH (key_field='id');
```
