Get started locally with our Curlbash installer, Docker, or Postgres.app.

<Tabs>
<Tab title="Curlbash">

```bash
curl -fsSL https://paradedb.com/install.sh | sh
```

The Curlbash installer starts ParadeDB in Docker with persistent storage, prints your connection credentials, and opens a `psql` session. Save the generated password to connect from your application.

The installer binds PostgreSQL to `127.0.0.1` by default. To allow remote connections, explicitly set `PDB_BIND_ADDRESS` to the desired host address (for example, `0.0.0.0`) and restrict access with your firewall. Environment variables must be passed to `sh` when using the piped command:

```bash
curl -fsSL https://paradedb.com/install.sh | PDB_BIND_ADDRESS=0.0.0.0 sh
```

To download, inspect, and verify the installer before running it:

```bash
curl -fsSL https://paradedb.com/install.sh -o install.sh
curl -fsSL 'https://paradedb.com/install.sh?checksum=1' -o install.sh.sha256
shasum -a 256 -c install.sh.sha256 && sh install.sh
```

The checksum detects a mismatched download; it is served by the same website and does not independently authenticate the installer. If the website updates between downloads, download both files again and verify before running.

The default Docker image is pinned by digest. `PDB_IMAGE` or an explicit `?tag=...` installer URL overrides that pin. Pin updates require a new installer revision.

To reconnect later, run:

```bash
docker exec -it paradedb psql -U postgres -d paradedb
```

</Tab>
<Tab title="Docker">

```bash
docker run \
  --name paradedb \
  -e POSTGRES_USER=postgres \
  -e POSTGRES_PASSWORD=mygoodpassword \
  -e POSTGRES_DB=paradedb \
  -v paradedb_data:/var/lib/postgresql/ \
  -p 127.0.0.1:5432:5432 \
  -d \
  paradedb/paradedb:latest
```

The Docker example also binds to localhost. Only change `127.0.0.1` when remote access is needed, and restrict access with your firewall.

Replace `mygoodpassword` with a strong, unique password and adjust the username and database name as needed. To connect, run:

```bash
docker exec -it paradedb psql -U postgres -d paradedb -W
```

</Tab>
<Tab title="Postgres.app (macOS)">

These steps assume you have [Postgres.app](https://postgresapp.com/) running PostgreSQL 18.

1. Download the `pg_search` installer from the [Postgres.app extensions page](https://postgresapp.com/extensions/) and install it.
2. Connect to your database via `psql`, run `SHOW config_file;` to locate `postgresql.conf`, then add `pg_search` to `shared_preload_libraries`:

```ini
shared_preload_libraries = 'pg_search'
```

If other libraries are already listed, keep them and append `pg_search` to the comma-separated list. Stop and start the Postgres server to apply the change.

Lastly, connect to your database via `psql` and enable ParadeDB:

```sql
CREATE EXTENSION pg_search CASCADE;
```

Postgres.app includes pgvector, which `CASCADE` enables automatically.
