<Note>

</Note>

Get started locally with the ParadeDB image using our Curlbash installer or via Docker directly.

<Tabs>
<Tab title="Curlbash">

```bash
curl -fsSL https://paradedb.com/install.sh | sh
```

The installer starts ParadeDB in Docker with persistent storage, prints your connection credentials, and opens a `psql` session. Save the generated password to connect from your application.

To reconnect later, run:

```bash
docker exec -it paradedb psql -U postgres -d paradedb
```

</Tab>
<Tab title="Docker">

```bash
docker run \
  --name paradedb \
  -e POSTGRES_USER=myuser \
  -e POSTGRES_PASSWORD=mypassword \
  -e POSTGRES_DB=mydatabase \
  -v paradedb_data:/var/lib/postgresql/ \
  -p 5432:5432 \
  -d \
  paradedb/paradedb:latest
```

Replace `myuser`, `mypassword`, and `mydatabase` with your preferred credentials. Then connect to ParadeDB:

```bash
docker exec -it paradedb psql -U myuser -d mydatabase -W
```

</Tab>
</Tabs>
