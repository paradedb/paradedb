# SchemaBot

SchemaBot is a schema diff and migration validation tool for PostgreSQL. We use it in CI to detect pg_search schema changes and check that migration fragments include the required SQL statements.

## Quickstart

Run these commands from the repository root. Building requires Rust, a C compiler, libclang, and protoc. On Ubuntu, install the build dependencies with:

```bash
sudo apt install clang libclang-dev lld protobuf-compiler
```

- Generate a suggested migration between two SQL schema files:

```bash
cargo run -p schemabot --locked -- diff base.sql head.sql > diff.sql
```

- Check that migration fragments contain the required statements:

```bash
cargo run -p schemabot --locked -- check diff.sql migration.sql
```

`check` accepts multiple fragment paths and allows additional statements. Review the SQL generated by `diff` before applying it; unsupported schema changes return an error.

## Development

Run the tests with:

```bash
cargo test -p schemabot --locked
```

The [Test SchemaBot workflow](../.github/workflows/test-schemabot.yml) builds and tests the crate. The [pg_search schema workflow](../.github/workflows/test-pg_search-schema.yml) generates schemas with `cargo pgrx schema` and checks the migration fragments in `pg_search/sql/unreleased/`.
